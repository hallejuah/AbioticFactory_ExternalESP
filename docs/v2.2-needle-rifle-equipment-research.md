# v2.2 — Needle Rifle equipment research (read-only)

## Purpose
The v2.1 report established these reflected links to the local
`Abiotic_PlayerCharacter_C`:

- `Abiotic_PlayerController_C.MyPlayerCharacter` at +0xF78
- `Controller.Pawn` at +0x2D8
- Other observed aliases: `PlayerCharacter` +0x860 and
  `AcknowledgedPawn` +0x340 (not used for validation here).

v2.2 checks that **MyPlayerCharacter and Pawn refer to the same valid
`Abiotic_PlayerCharacter_C`** before researching that character's equipment.
This is deliberately a strict fail-closed gate for the tested game build.

## Test on the Needle Rifle
1. Build Windows x64 Release from `feature/v2.2-needle-rifle-equipment-research`.
2. With the Needle Rifle in hand press **F11** once.
3. Switch to another item (or empty hands), press **F11** again.
4. Equip the rifle, fire a few shots, and press **F11** again.
5. Send `abiotic_needle_rifle_research.txt` alongside `AbioticESP.exe`.
   Indicate which of the three snapshots corresponds to which equipment state.

## Collected data
- Revalidates the world/local player/controller/camera chain.
- On matching validated character pointers, inspects reflected properties
  whose names suggest weapon, firing, recoil, spread, equipped gear,
  inventory, held item, ammunition, attack, hand or wielding.
- For object-property candidate offsets, logs only referenced UObject
  **class names** if recognized; does not traverse unverified nested links.
- Scans up to 0x1800 bytes of controller or character for at most 240
  distinct plausible references per object, showing directly owned
  candidate equipment/weapon-like components.
- Reflection traversal is bounded to 8 classes, 384 property fields per
  class and 64 reported name matches per object.

**Important:** Candidate offsets and matching names do not establish
the actual weapon implementation. No Rapid Fire / No Recoil writes or
patches exist yet. The diagnostics are read-only; Box ESP remains
operational. F2 and F12 stay disabled.

The executable SHA256 gate is unchanged. MSVC build and live game test
have not been independently verified.
