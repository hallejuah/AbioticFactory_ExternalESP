# v1.6 — CustomDepth experiment (WIP — DO NOT RUN)

This branch is a **work-in-progress** experimental memory modification. The code has not been compiled or tested.

## Blocking issues

- The temporary WriteProcessMemory handle currently omits PROCESS_VM_OPERATION. On Windows this is required for WriteProcessMemory, so the write will normally fail.
- An error between writing and post-write confirmation can leave restoration unarmed. The implementation must arm its restoration state before post-write confirmation.
- A process crash or game unloading its actor can prevent restoration. Restart the game if the state becomes uncertain.
- No durable log file has been integrated yet.
- Writing a reflected UE property directly does not necessarily call SetRenderCustomDepth or invalidate its render state. A visible outline is not guaranteed.

Do not use F2 or treat this branch as a completed test until the blockers are corrected, code is reviewed and a Windows x64 Release build succeeds.

## Intended experiment after fixes

F2 will briefly enable a single Pest's CustomDepth bool bit (candidate Mesh+0x269, mask 0x40) for at most five seconds, with actor ownership, class, reflection and SHA256-based attach checks, plus restoration. This is **not** a native outline shader. Skeleton modes remain available.

The tested game must be a locally controlled single-player session with a backed-up save. No injection or rendering hook is included.
