# v1.6 — CustomDepth trial (draft, untested)

## Fixes made in this branch

- OpenProcess requests PROCESS_VM_READ, PROCESS_VM_WRITE,
  PROCESS_VM_OPERATION and PROCESS_QUERY_LIMITED_INFORMATION for the manual
  one-byte operation only; ordinary ESP reads are unchanged.
- Byte field addresses can be unaligned; the general UObject validPtr
  alignment check must not reject mesh+0x269.
- Restoration state is armed BEFORE the write attempt and is retained on
  write or post-write verification errors until resolved.
- Normal End-key/window close paths attempt restoration and refuse ordinary
  shutdown while a retry remains pending.
- Trial start, failures and restoration results append to
  abiotic_customdepth_test.txt beside AbioticESP.exe.

## Important limitations

**Still a draft; Windows VS 2026 build and gameplay have NOT been tested.**
Manual testing may crash the game, and a forced termination, game crash or
destruction of the target UObject can prevent recovery. In that case quit
and restart the game. Never assume rollback is guaranteed.

Direct field writes do NOT call SetRenderCustomDepth, mark the render state
dirty or install a CustomDepth post-process shader. A correct memory write
can produce no visible outline.

The temporary F2 trial targets a single Pest with validated direct-owned
SkeletalMeshComponent and OutlineComponent_C and exact candidate
FBoolProperty reflection metadata (Mesh+0x269, bit 0x40). It refuses an
already enabled CustomDepth bit. A successful trial lasts at most five
seconds, after which the original bit is restored if the target remains
valid. No memory writes are performed at launch.

## After local compilation succeeds

1. Backup the single-player save and close unnecessary background tools.
2. Build x64 Release from feature/v1.6-customdepth-trial.
3. Position one Pest near the centre of the view and press F2 once.
4. Observe the game for five seconds, without killing or despawning Pest.
5. Review abiotic_customdepth_test.txt for a successful restoration.
6. If restoration is pending or fails, close and restart the game.
7. Send the log and say whether any visual change appeared.

The game executable's SHA256 verification remains enforced in Process::attach.
This is not yet a reliable native mesh-silhouette outline feature.
