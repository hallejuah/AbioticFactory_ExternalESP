# v0.4 manual verification (Windows x64)

The ESP remains **external and read-only**. It does not write memory or inject into the game.

1. Run `build\Release\AbioticESP.exe` **before** launching Abiotic Factor. Confirm it remains open, then start the game. It should attach once the supported SHA256 build is running.
2. Close the game while ESP is open. The overlay should remain alive with no stale labels. Restart the game. The ESP should reconnect without restarting itself.
3. Move between streamed UE levels. Actor counts should update, and scan failures should not crash the UI.
4. Open F10, switch categories, and keep the panel in focus while checking that the ESP stays visible.
5. To view diagnostics, run a debugger/DebugView and inspect `OutputDebugString`: `actors`, `scans`, `scan_last_ms`, `scan_avg_ms`, `scan_errors`, `read_errors`, `reconnects`.
6. Under the System tab, reopen the panel to refresh visible cumulative scan / read error / reconnect counts.
7. Check `End` exits and settings are saved.

Notes: Process SHA256 is rechecked on every attachment; mismatches remain blocked. A failed initial attach is retried about every 3 seconds. The scan timer remains independently configurable.
