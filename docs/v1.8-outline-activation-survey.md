# v1.8 — Outline activation comparison survey

This is a manual, **read-only** survey to find a naturally active
`OutlineComponent_C` instance that can be compared with the inactive Pest
instance observed in v1.7.

## Test
1. Check out `feature/v1.8-outline-activation-survey` and build Windows x64 Release.
2. Start Abiotic Factor and AbioticESP.
3. Press **F12** once near Pest; survey reads scanner-known actors (not just
   the centred Pest), at most 80 validated actors per invocation.
4. Move to an area containing other enemies, NPCs and interactive objects;
   force an actor scan with F9 if needed, then press F12 again.
5. Send `abiotic_outline_survey.txt` next to AbioticESP.exe.

F2 continues to be **disabled** in this v1.8 research branch.
The B-key debug skeleton modes remain unchanged.

## Bounded scope and caveats
- Scans at most 80 already discovered, categorized Actor UObjects and the
  first 0x1000 bytes of direct-owned UObject pointers of each one.
- At most 8 OutlineComponent_C candidates per actor, 8,000 validated owned
  object lookups overall. Reports OutlineMask, ComponentEnabled, the candidate
  RegisteredComponents TArray header, and any registered class names (max 12).
- If a valid owned SkeletalMeshComponent is found, also reports its candidate
  bRenderCustomDepth bit.
- Reports a summary count of outlines with nonzero mask or nonempty
  registered component arrays, **not a claim that a visible effect exists**.
- The regular scanner only keeps recognized actor categories; this is not an
  enumeration of all game objects. A zero match is not conclusive.
- The sampled metadata and fixed offsets remain executable-build-specific.
- No writes, UE function calls, material changes or rendering hooks.

Compilation and runtime behavior have not yet been tested on Windows.
