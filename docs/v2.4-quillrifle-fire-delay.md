# v2.4 — QuillRifle FireDelayDuration and recoil tracks (READ ONLY)

v2.3 identified a reflected `DoubleProperty`:
`Abiotic_Weapon_ParentBP_C.FireDelayDuration` at held
`Abiotic_Weapon_QuillRifle_C + 0xB28`.

F11 now reads and reports that value only when the current weapon passes
the validated QuillRifle class gate. It also reads two candidate recoil
timeline track floats from the player character:
- `ControllerRecoilTimeline_NewTrack_0` at +0x17B0
- `RecoilTimeline_NewTrack_0` at +0x1800

These are instantaneous snapshots, NOT continuous sampling. Timeline
values may return to zero before the F11 keypress is processed.

## Test
1. Checkout `feature/v2.4-quillrifle-fire-delay-values`; build x64 Release.
2. Equip the Quill Rifle, press F11 with no shooting.
3. Shoot, then press F11 as quickly as possible after a shot.
4. Equip a different weapon and press F11 again.
5. Upload the resulting `abiotic_needle_rifle_research.txt` from the
   executable directory.

Only reflectively identified numeric candidate offsets are read.
Finite/range validation of the read values is applied. No memory write,
no fire-rate modification, no recoil manipulation. Box ESP and executable
SHA256 verification remain as before. The MSVC build is unverified.
