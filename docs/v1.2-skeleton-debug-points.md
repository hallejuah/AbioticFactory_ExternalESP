# v1.2 — Skeleton debug points (Pest only)

## Scope
This is the **first in-game visualization**, not a contour or connected skeleton.
It projects ten component-space bone translations onto screen as small cyan
numbered dots. Disabled by default.

## Controls
- **B**: toggle numbered dots.
- **F10 > settings**: checkbox `Skeleton debug (Pest only)`.
- **F12**: keep the v1.1 bone transform text diagnostic.

## Test
1. Build x64 Release from `feature/v1.2-skeleton-debug-points`.
2. Start Abiotic Factor and ESP. Stand where a Pest is visible.
3. Press B. You should see 0–9 next to dots **if the unverified
   ComponentToWorld transform offset validates**.
4. Rotate the camera, approach the Pest and take a screenshot. Check whether
   the points actually stay on the body.
5. If nothing appears, send a screenshot and explain whether ESP labels
   appear normally; the guessed transform offset likely needs correction.
6. Toggle B off to return to ordinary ESP.

## Guardrails and known limitations
- Only Pest; do not reuse layout for Peccary/Robot without validating it.
- Read-only: reads mesh+0x988 component-space array (10 x 96-byte transforms),
  and hypothesized `SceneComponent::ComponentToWorld` at mesh+0x1D0.
- The **mesh+0x1D0 offset is NOT yet validated** for this game build.
  Projection is skipped unless quaternion/scales are plausible and world
  translation lies within 400 UE units of the root's validated world location.
- Sampling at most once per 50ms for **one Pest**, no new injection or writes.
- No known bone names or parent links, no lines, no actual pixel outline.
  Inaccurate positions must be reported rather than silently corrected.
