# v2.7 — Numpad controls and visible diagnostic status

The v2.6 F1 feedback was written to the internal status/debug channel
but was not rendered in the in-game ESP overlay, making it difficult to
tell whether a trial actually started. v2.7 renders a yellow diagnostic
message at the upper left for about five seconds.

## Controls (numeric keypad, Num Lock ON)
- **Numpad1**: arm/stop the optional, time-limited Quill Rifle recoil trial.
  Only starts if the validated Quill Rifle is held and recoil is zero.
  The message shows whether arming succeeded and the exact failure reason.
- **Numpad2**: collect read-only 2-second CSV samples to
  `abiotic_quillrifle_samples.csv`.
- **Numpad0**: display control help on the overlay.
- **End**: exit (existing behavior).

F1 and F11 no longer invoke these experimental weapon features. Other
existing F3–F10 categories/settings hotkeys remain unchanged.

## Test
1. Build the x64 Release binary of this branch.
2. Launch the game and ESP. Press Numpad0, confirming a yellow message.
3. Equip Quill Rifle, stop firing until idle, then press Numpad1.
   The status should say it is active for 1.5 seconds, or why it failed.
4. Press Numpad2 while equipped and shoot for the next two seconds;
   check the on-screen CSV result.

The underlying **No Recoil trial is not proven effective**: v2.6 did not
produce an observed camera change. This PR fixes controls and visibility,
not the actual camera recoil mechanism. All existing safety/identity
checks and automatic cutoff remain intact. No Rapid Fire is implemented.
Windows MSVC and live tests still need user verification.
