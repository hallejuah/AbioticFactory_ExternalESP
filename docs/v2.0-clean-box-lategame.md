# v2.0 Clean Box ESP — expanded late-game NPC detection

## What changed
- Hostiles recognized by class families: `NPC_Monster_*_C`, `NPC_Robot_*_C` and `NPC_Zombie_*_C`, plus the user-observed `NPC_Exor_Pikeman_C`, `NPC_Exor_Monk_C`, `NPC_Peccary_Mushroom_C`.
- A 2D rectangular box is drawn around recognized hostiles. Its top uses a projected approximate height from the actor root, and its width is scaled from that height. **These are not verified mesh bounds** and may need species-specific tuning.
- Research hotkeys F2 (memory write), F11 and F12 are disabled in normal gameplay; B skeleton debug is disabled.
- Existing text labels, distance, and verified health/armor display remain. Only previously verified classes use the known health memory layout; new types show HP:? rather than an unverified reading.
- Each successful scanner refresh writes `abiotic_hostile_classes.txt` next to `AbioticESP.exe`: recognized NPC class counts and unclassified `NPC_*` class candidates.

## Late-game save validation
1. Build Windows x64 Release from `feature/v2.0-clean-box-expanded-hostiles`.
2. Load the late-game save and launch ESP.
3. Press F9 to rescan, wait a moment, and check which creatures get boxes.
4. Send `abiotic_hostile_classes.txt` plus the **exact name or screenshot** of any missing creature.
5. Check the Enemies checkbox, ESP max distance and max labels if something nearby still does not show.

The two supplied late-game reports also contain `NPC_Boxy_C` and `NPC_Coworker_C`, deliberately kept unclassified because an `NPC_` prefix alone does not prove hostility.\n\nNote: NPC prefixes do not prove hostility. An NPC_Robot subclass may be neutral; these prefixed types are placed in the hostile category provisionally. Other actor naming families may exist, and the report will help identify them. Only scanner-recognized actors and NPC-prefixed unknown class names are logged; this is not a full game class inventory.

The exact game executable SHA256 check remains in place. No memory writes or engine hooks are initiated by this mode. The historical research source files remain in the branch but their gameplay controls are not active.
