# ESP v1.3 — tentative skeleton connections (Pest)

## Controls

Press **B** to cycle three modes:
- Off
- Numbered points (cyan)
- Numbered points with experimental lines (amber)

The F10 settings panel has a checkbox that turns the skeleton feature on
(points mode) or off. The mode label reflects the most recent B-key choice.
The mode is saved to `abiotic_cpp_settings.ini` as `skeletonMode=0/1/2`;
older `skeletonDebug=1` settings are accepted as points mode.

## Tentative edges

`0-1, 1-2, 2-3, 3-4, 4-5, 4-6, 5-7, 6-8, 2-9`

These are **guesses based on a single Pest screenshot**; they have not been
verified against the actual skeleton parent indices. Do not treat these
links as an exact UE skeletal hierarchy or a model outline.

Links are drawn only when both numbered bone points are valid and on-screen;
lines greater than 400 pixels are suppressed while testing. The existing
guarded v1.2 bone point projection and 50 ms sample cadence are unchanged.

## Test

1. Build the `feature/v1.3-skeleton-lines` branch (VS 2026 x64 Release).
2. Find a Pest. Press B once: verify the numbered dots.
3. Press B again: verify amber lines connect plausible body points.
4. Move around or wait for an animation; take a screenshot from the side.
5. Press B a third time to disable all points and lines.
6. Share a screenshot highlighting any incorrect links.

## Boundaries

Pest only; external read-only GDI overlay; no writes, injection or hooks.
No game-native CustomDepth, mesh pixel silhouette, or validated bone hierarchy.
Visual correctness requires in-game testing; Windows compilation is not
verified in the authoring environment.
