# v2.1 Needle Rifle — read-only weapon research

Goal: discover the actual equipped-weapon link and firing/recoil state
for the **Needle Rifle**. The known world/local player/controller chain
is validated; existing offsets do not yet establish the weapon pointer,
its rate of fire, or recoil fields.

## Test procedure
1. Build Windows x64 Release from `feature/v2.1-needle-rifle-research`.
2. Start game in solo/offline play and launch ESP.
3. Equip the **Needle Rifle**, then press **F11** once.
4. Equip another item or put the rifle away, press **F11** again.
5. Optionally equip the rifle and fire a few shots before a third F11.
6. Send `abiotic_needle_rifle_research.txt` from the executable folder.

F11 is the only newly enabled diagnostic hotkey. The normal box ESP
still works. **F2 writes and F12 research remain disabled.**

## Data and limitations
- Reflects matching property-name candidates (weapon, fire, recoil,
  spread, shoot, equip, pawn, character) in the local player/controller
  class ancestry, at most 8 classes, 384 fields per class, 64 matches.
- Examines a bounded 0x600-byte region of the controller for directly
  owned interesting UObject references, up to 96 candidate pointers.
- Does not assume an FProperty offset is correct simply because its
  name looks promising, and does not traverse arbitrary weapon pointers.
- Some UE pawn/equipment properties may be held in structures not
  reachable from these two objects; zero matches will mean only that
  this limited probe did not find them.
- No Rapid Fire or No Recoil effect is implemented yet.
- No memory writes, injection, engine method calls, or rendering hooks.

Strict executable SHA256 verification remains. Windows MSVC compile
and runtime validation still need to be performed.
