# v2.6 — QuillRifle No Recoil experimental trial

**Explicit opt-in:** F1 initiates an experimental, 1.5-second, single-field
memory-write test only while `Abiotic_Weapon_QuillRifle_C` is held.
F1 again ends it early. It is disabled by default. It does not run on
any other equipped class.

## Validation and behavior
- Strict executable SHA256 gate remains in Process::attach.
- Rechecks UWorld/local-player/controller/camera and verifies two
  PlayerCharacter references agree at the start.
- The equipped object must have class `Abiotic_Weapon_QuillRifle_C`.
- `Abiotic_PlayerCharacter_C.AimRecoilAdditive` is a reflected
  DoubleProperty, address `PlayerCharacter+0x1A00`.
- **Arming requires its original value to be exactly zero**, when idle.
  During the 1.5-second test, a strictly positive finite value at most
  10 may be changed to zero by an exact compare-before-write.
- Writes use a separately opened, short-lived VM_WRITE process handle,
  never elevate the ordinary scanner/read-only handle.
- Maximum 90 writes. Verifies each changed field by a subsequent read.
- Automatically stops if the rifle or character changes, on timeout,
  explicit F1, END, or shutdown; no memory writes after the test.
- As the only admitted baseline is zero and the only written value
  is zero, there is no nonzero user-set value to restore. At shutdown
  it deliberately **does not overwrite a later engine-generated recoil
  impulse** with a stale snapshot. The game may update this field
  continuously, so full engine-level restoration cannot be guaranteed.
- F11 read-only timed CSV sampling continues to work independently.

## Test
1. Use a backup late-game save; use solo/offline only.
2. Build Release and launch Box ESP.
3. Equip the Quill Rifle and stop shooting until idle.
4. Start firing and tap F1; the effect lasts at most 1.5 seconds.
5. Compare how the crosshair/camera responds compared with normal
   firing. F1 again aborts early. Check DebugView/OutputDebugStringA
   for the count of successful zero writes and validation errors.
6. Report whether the camera kick actually changed, and if there were
   any game crashes or compilation errors.

**Not implemented:** Rapid Fire, guaranteed zero recoil, permanent
field patches, modifying `RecoilTimeline` or `FireDelayDuration`.
The experiment is deliberately narrow because field meaning is not
yet verified by a write test.
Windows x64 MSVC build and live gameplay verification are pending.
