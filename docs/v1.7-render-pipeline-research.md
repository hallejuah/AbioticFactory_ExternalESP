# v1.7 — Render State & Outline Pipeline Research

This is a **read-only research build** following the v1.6 experiment: the
bRenderCustomDepth bit could be set and restored, but the user saw **no
visible change**. An in-memory bool write does not necessarily update the
render thread or create a visible outline.

## Usage
1. Build Windows x64 Release on branch `feature/v1.7-render-pipeline-research`.
2. Find a Pest in single-player Abiotic Factor and aim near it.
3. Press **F12** once. This is a manual, bounded probe.
4. Find `abiotic_render_pipeline.txt` alongside `AbioticESP.exe`.
5. If convenient, repeat on Carbuncle.
6. Send the report.

**F2 is disabled in this branch.** It will not repeat the memory write
experiment. B still cycles the debug skeleton view.

## Information collected
- Checks actor, mesh and outline class identity and direct ownership.
- Reads candidate OutlineMask, ComponentEnabled, RenderCustomDepth,
  CustomDepthStencilValue and OverlayMaterial state.
- Reads a **bounded** candidate RegisteredComponents TArray; dereferences
  no more than 16 object references only if count/capacity/pointer validate.
- Scans at most 0x1000 bytes of actor memory, examines at most 160 distinct
  plausible object references and prints directly-owned interesting
  components (outline, postprocess, mesh, highlight, stencil or material
  classes).
- Reports values as memory observations, **not** as evidence that the render
  thread has been refreshed or a native outline shader is installed.

No new external process writes, injection, render hook, engine-function
invocations or shader/material modifications. Candidate offsets are still
specific to the previously tested executable SHA256.

## Interpret carefully
An empty RegisteredComponents array and a missing postprocess component are
not proof that no outline material is active anywhere: post-process
materials may live elsewhere in the world, player camera or rendering
pipeline. An external read-only probe cannot conclusively establish
render-thread proxy state.

Windows VS 2026 build and in-game output have not been verified yet.
