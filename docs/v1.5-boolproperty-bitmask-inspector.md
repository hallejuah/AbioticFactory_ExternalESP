# v1.5 — FBoolProperty Bitmask Inspector

## Purpose

Read-only analysis of Unreal Engine FBoolProperty metadata for a single, visible hostile actor. This is preparation for studying CustomDepth and native outlines; **no game-memory writes are performed**.

## How to test

1. Switch to `feature/v1.5-boolproperty-bitmask-inspector`.
2. Build the Windows x64 Release configuration.
3. Launch Abiotic Factor and AbioticESP.exe.
4. Aim near a living Pest and press **F12** once.
5. Find `abiotic_bool_masks.txt` next to AbioticESP.exe.
6. If possible, repeat for a Carbuncle; send the report.

The **B** key continues to cycle Pest skeleton debug modes. F11 still runs the mesh probe.

## Data collected

- Verifies actor and direct-owned SkeletalMeshComponent (+0x320) and OutlineComponent_C (+0x9D8).
- Traverses up to eight reflected superclass chains, with at most 512 properties per class.
- Selects rendering and outline boolean property names, including bRenderCustomDepth, bRenderInMainPass, bRenderInDepthPass, ComponentEnabled, bVisible and bHiddenInGame.
- Prints candidate Offset_Internal and the raw byte at that instance location.
- Prints 48 raw candidate metadata bytes from each matching FBoolProperty (property+0x60 through property+0x8f).
- Compares hypothetical FBoolProperty packing at property+0x70 and +0x78. The resulting field sizes, byte offsets, and masks are **hypotheses** and explicitly **not write targets**.

## Limitations

Reflection offsets and metadata structures are still unverified for this exact build. A plausible mask is not proof of correctness or of a working outline shader. A future write experiment must separately verify the bit semantics, game executable hash, component ownership, and reliable restoration; it must not write using these guesses alone. No process writing is enabled in v1.5.

Windows/VS 2026 compilation and the result in-game require local verification.
