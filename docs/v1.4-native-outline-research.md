# v1.4 — Native Outline Research (read-only)

This release studies Unreal's existing OutlineComponent_C and SkeletalMeshComponent. It does not write game memory or enable outlines.

## Test

1. Build the feature branch Release/x64 with VS 2026.
2. Position a live Pest close to the screen centre.
3. Press F12 once; read abiotic_native_outline.txt beside AbioticESP.exe.
4. Repeat on Carbuncle if possible. Share the report.

B still cycles skeleton display modes and F11 retains mesh diagnostics.

## Research scope

The inspector first validates the owning actor and component classes at Actor+0x320 and Actor+0x9D8. It then searches bounded candidate reflection metadata for OutlineMask, RegisteredComponents, ComponentEnabled, bRenderCustomDepth, CustomDepthStencilValue, CustomDepthStencilWriteMask, OverlayMaterial, OverrideMaterials, bRenderInMainPass, bRenderInDepthPass, bVisible, bHiddenInGame and bOwnerNoSee.

Traversal limits: 8 classes, 512 candidate fields per class, one manual F12 probe. Reported instance offsets and FBoolProperty masks remain hypotheses; the report shows raw values for comparison and does not authorize writing those offsets.

Finding these properties does not prove that CustomDepth or a stencil effect is active. The game may require registered components, materials and postprocessing. No exact model outline is rendered. SHA256 executable verification and read-only process access remain unchanged.
